
## MeetingMind-AI Meeting-Intelligence platform  
MeetingMind is a modern **AI-powered meeting intelligence platform UI** designed to help teams manage, analyze, and organize meetings efficiently.

This project focuses on **clean UI design, modern dashboard layout, and user experience** for productivity tools.


##  Features

- Modern **Landing Page**
- Clean **Dashboard UI**
- Responsive Layout
- Smooth animations
- Component-based architecture
- Professional SaaS-style interface


## 🖥️ Tech Stack
  Frontend 
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Tanstack query 

Backend 
- Prisma Postgresql
- express js
- Typescript
- Socket io
- Webrtc
- speed to text
- LLM Processing
